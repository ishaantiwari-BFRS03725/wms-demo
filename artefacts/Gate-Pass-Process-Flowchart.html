End-to-end process, grouped by actor and location.

Demo WMS process flow — Gate Pass Processing (inbound / return / outbound) and Unloading. For Unicommerce / EasyEcom sellers, Unloading is the last step in this WMS for inbound and returns — once stock is accepted, the rest of the process (putaway, inventory, etc.) is handled in the seller's own platform. For WMS 2.0 / Maven sellers, the next step continues within this WMS itself.
