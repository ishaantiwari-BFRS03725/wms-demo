Pain points on a 3–4″ HHT screen
  • Redundant counts. The IDENTIFIED / UNIDENTIFIED stat tiles repeat numbers already shown in each pile's header, eating a full row of screen height for no new information.
  • Complete can drop off-screen. It's the most-tapped action at the end of a gate pass, but with two piles and a stat row ahead of it, it's pushed further from the thumb as more AWBs are scanned.
  • Mark Damaged competes with the AWB. A small red pill sits inline with the scan code on every row, narrowing the tap target and crowding the primary "what did I just scan" information.
  • Gate pass context wraps. Seller + courier + gate pass number sit to the right of the scan label and wrap awkwardly once the screen narrows below tablet width.

What changed for a 3–4″ HHT screen
  • Both piles still stack below the scan box — same order, same labels, same data as today. Nothing moved behind a tab or a swipe.
  • Counts moved into the pile headers (IDENTIFIED 1) instead of a separate stat row, so the same information takes one line, not two.
  • Gate pass, seller and courier collapse into one strip under the title, so they stop wrapping once the screen narrows below tablet width.
  • Mark Damaged is a full-width button under each row instead of a small pill squeezed next to the AWB — easier to hit reliably on a handheld without mis-tapping the code.
  • Complete stays visible at the bottom of the same screen the piles are on — no separate step, just tighter spacing above it so it doesn't get pushed past the fold as AWBs stack up.
